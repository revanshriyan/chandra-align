## What this bench settles

- **RIFT2 is functional.** On the fixed `_mutual_nn` code it produced
  the best synthetic result of the day (0.1398 px, ACCEPTED) and a
  COARSE fit on OHRC (2.0185 px, 48 inliers). The October "RIFT2
  non-functional" verdict (0–1 correspondences) was measured on the
  buggy `_mutual_nn` backward-set ordering, fixed in `84fdb307`; that
  verdict is superseded by this bench. RIFT2 remains opt-in
  (`CHANDRA_ENABLE_RIFT2=1`) and disabled by default — the standing
  reason is now the unresolved vendored-code license question
  (`docs/rift2-license-review-2026-10-07.md`), not functionality.
- **The strip guard fires end-to-end on its calibration case.** Both
  TMC-2 arms with enough yield were rejected STRIP_COLLAPSE with
  minor_ratio 0.075 < 0.159 — the same inlier signature (13 inliers)
  whose landmark RMSE is 28.03 px. In the October guard-off runs the
  same pair reported COARSE.
- **LightGlue synthetic moved across the 0.50 line** (0.3695 px in
  October → 0.5061 px here, COARSE). The matcher library is unpinned,
  so this is reported as library drift, not a repo regression. Its
  OHRC result improved (1.7961 → 1.5381 px) and is the best OHRC arm
  in this bench.

## Run notes

- The first LightGlue attempt in this session returned "model not
  available" on all three pairs (NOT MEASURED): Colab preinstalls
  torchvision built for a different CUDA than the repo's torch, and
  torchvision raises RuntimeError — not ImportError — on the
  mismatch, so the graceful-degradation guard does not catch it. The
  rerun used torchvision 0.26.0+cu128 matched to torch 2.11.0+cu128;
  all LightGlue rows above are from that rerun.
- Total matcher runtime across the nine rows: ~259 s on the T4.
